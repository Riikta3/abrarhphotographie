# Photography Website Design Guidelines

## Design Approach
**Reference-Based Approach** - Drawing inspiration from premium photography portfolios like those found on Behance and award-winning photographer websites. The design should reflect the elegance and artistry of professional photography while maintaining accessibility for potential clients.

## Core Design Elements

### Color Palette
**Light Mode:**
- Primary: 20 15% 15% (Deep charcoal for elegance)
- Background: 0 0% 98% (Warm white for photo contrast)
- Accent: 25 80% 45% (Warm gold for French luxury feel)

**Dark Mode:**
- Primary: 0 0% 95% (Soft white)
- Background: 210 15% 8% (Rich dark for photo galleries)
- Accent: 25 70% 55% (Muted gold)

### Typography
- **Primary Font:** Playfair Display (Google Fonts) - Elegant serif for headings
- **Secondary Font:** Inter (Google Fonts) - Clean sans-serif for body text
- **Accent Font:** Dancing Script (Google Fonts) - Script for signature/taglines

### Layout System
Tailwind spacing units: 4, 8, 16, 24 (p-4, m-8, gap-16, py-24)
- Generous whitespace to let photography breathe
- Asymmetrical layouts for visual interest
- Grid-based gallery systems

### Component Library
- **Hero Section:** Full-viewport with overlay text and CTA
- **Photo Cards:** Hover effects with soft shadows
- **Navigation:** Minimal, elegant with French typography
- **Contact Forms:** Clean, professional styling
- **Gallery Grids:** Masonry and standard grid layouts

## Visual Treatment

### Gradients
- Subtle overlay gradients: From 0 0% 0% 0% to 0 0% 0% 60% for hero images
- Background gradients: 25 20% 96% to 210 25% 98% for section dividers

### Photography Focus
- Large, high-quality hero images showcasing work
- Gallery thumbnails with smooth hover transitions
- Image-first design philosophy with text as supporting element

## Page Structure

### Home Page (3 sections max)
1. **Hero:** Full-screen photography showcase with service tagline
2. **Services:** Wedding, couple, family, maternity with representative images
3. **Contact CTA:** Simple, elegant call-to-action

### About Me
Personal photographer portrait, story, and approach with warm, inviting layout

### Gallery
Organized by service type with elegant filtering and lightbox functionality

### Contact
Clean form with Paris location emphasis and booking information

## Images
- **Hero Image:** Large, stunning wedding or couple photo showcasing style
- **Service Images:** High-quality representative photos for each category
- **About Image:** Professional but approachable photographer portrait
- **Gallery Images:** Curated selection of best work, properly optimized

The design should exude French elegance while remaining accessible to families and couples seeking photography services.
